#### 使用示例：
- 产品列表，新建示例环境"示例产品"
- 在文件-用例管理页面：导入测试用例文件（示例产品.xmind）
- 产品列表，选中对应名称环境，点击Xmind导入测试用例，在用例菜单下即可看到对应测试用例数据

#### XMind文件
- demo：doc/file/project_V1.0.0_testcase_demo.xmind
- 字段说明：
    - 以 _ 下线线分割
    - project与测试环境录入的项目名称保持一致
    - 版本V1.0.0用来设置用例所属版本，通过case_id体现
    - demo中的模块名中文名与英文名用中划线-分割，通过case_id体现，未设置，默认置为other

#### 用例组成
- 用例编号: 按模块分类编号，以便数据统计和分析
- 用例名称: 功能聚焦，每一个用例有测试重点
- 用例类型: 功能/流程/界面/异常/易用性/回归/性能/安全/兼容性/场景/压力/长时间/环境/数据/文案/样式/交互/边界， 可自行定义
- 优先级: P1/P2/P3/P4或高/中/低, 可自行定义
- 预置条件
- 测试范围
- 测试步骤
- 预期结果
- 测试过程: 测试过程记录, 一般为截图（多张，保存为文件路径列表）
- 扩展信息: 额外信息，YAML 键值对格式，导出时可引用
- 是否自动化: 是/否
- 功能开发者
- 用例设计者
- 用例执行者
- 测试时间: 执行时间记录
- 测试结果: 通过/部分通过/失败/未测试/已废弃
- 用例模块: 设置用例归属的模块，以便数据统计和分析
- 引入版本: 设置用例引用的版本信息
- 关联场景: 可关联自动化数据/场景，通过自动化的方式执行
- 关联产品: 关联执行环境或用例归属产品
- 备注: 问题澄清，问题单关联，变更原因等

#### 导入用例

##### 从XMind导入
- 在用例管理页面点击「导入」→「导入Xmind用例」，上传 .xmind 文件，格式要求见上文「使用示例」与「XMind文件」

##### 从Excel导入
- 点击「导入」→「导入Excel」进入导入页面
- 导入与 Excel 导出共用同一套模板机制：模板由系统参数 `testCaseExportTemplates` 定义，Excel 表头（列标题）映射到用例字段
- 填写用例后上传 Excel 文件；可同时上传图片包（`.zip`）导入测试过程截图
- 图片包命名：每张图片命名为「编号_N.格式」（如 `CASE_001_1.png`），以便关联到对应用例
- 提交后系统按「用例编号 + 模块」检测冲突：
  - 新用例直接插入
  - 已存在用例可选择跳过或覆盖（覆盖仅更新有值的字段）
- 生成的模板中的示例行（用例编号以「示例」开头）导入时自动跳过
- 可对未填写的字段统一填写默认值，导入时统一生效

#### 导出用例

##### 导出Markdown / XMind
- 勾选用例，点击「自定义导出」→「导出MD」/「导出Xmind」按对应格式导出

##### 导出Excel
- 点击「自定义导出」→「导出Excel」，配置：
  - 导出模板：选择预定义导出模板（定义导出列、列顺序与表头）
  - 导出语种：选择导出语种，本地化字段按所选语种导出，缺少译文时回退默认值
  - 图片模式：不导出图片 / 打包图片（截图写入单元格路径并打包图片）/ 嵌入图片（截图直接嵌入单元格）
  - EXCEL类型：图片模式为「嵌入图片」时可选 WPS / OFFICE
  - 打包格式：tgz / zip（仅「打包图片」模式生效）
  - 条件筛选：产品 / 引入版本 / 用例设计者 / 模块 / 创建时间，或直接导出勾选用例
- 导出结果为可下载的 `.xlsx`，或包含 `.xlsx` 与引用图片的 `.tgz`/`.zip` 压缩包

##### 从用例统计定义导出Excel
- 在用例统计定义列表勾选统计定义，点击「导出Excel」按钮
- 配置：
  - 导出模板：选择预定义导出模板
  - 导出语种：选择导出语种
  - 图片模式：不导出图片 / 打包图片 / 嵌入图片
- 导出范围由所选统计定义决定：导出各定义覆盖的全量用例，按模块分组，一个模块一个 `.xlsx`，最终打包为单个 `.zip`
- 数据过滤应用各定义自身的「引入版本」「产品」配置，跨定义按用例编号去重合并
