#### 任务类型
- 自定义任务: Crontab表达式，按需设置执行频率
- 一次任务: 执行一次即停止，可反复执行
- 每天任务: 按天维度设置执行任务
- 每周任务: 按周维护设置执行任务

#### 任务执行范围
- 数据类型任务
- 场景类型任务

#### 任务执行环境
- 可关联单个环境：功能测试，性能测试等
- 可关联多个环境：信创多环境，可一次执行
- 可不关联环境：直接使用场景关联的环境

#### Crontab表达式
```
* * * * *
- - - - -
| |  | | |
| |  | | +-------------- 星期中星期几 (0 - 6) (星期天 为0)
| |  | +---------------- 月份 (1 - 12)
| |  +------------------ 一个月中的第几天 (1 - 31)
| +---------------------- 小时 (0 - 23)
+------------------------- 分钟 (0 - 59)
```

#### 生成报告
- 单任务执行报告：任务每次执行完成后自动生成，可在任务列表每行的「报告」操作按钮跳转查看
- 多任务合并报告：
  1. 在任务列表勾选需要合并的任务（至少 2 个）
  2. 点击顶部「生成报告」按钮，选择关联产品（默认自动带出所选任务关联的产品）
  3. 提交后异步生成，按产品各生成一份合并报告，完成后在报告列表查看
- 覆盖范围报告：任务从未执行时，可根据任务配置（场景 / 数据 / 接口）静态解析自动化覆盖范围，无需执行历史

#### 导入数据
- 任务数据包导入：
  1. 在任务列表点击顶部「导入数据」按钮，进入导入页
  2. 上传「任务一键导出」生成的数据文件包（tgz/zip/tar，内含 task_info.yaml、playbook_info.yaml 及数据文件）
  3. 系统解析后按名称检测冲突（任务名称 / 场景名称 / 数据文件名称）
  4. 选择处理方式：跳过冲突项 / 覆盖冲突项 / 取消

#### 导出
- 任务上下游使用到的信息均会导出为SQL
- 涉及: 任务/产品/应用/场景/数据/断言模板/系统参数等表单的信息
- SQL生成规则：产品配置/应用配置，存在则跳过; 其他不存在则插入，存在则更新
- 数据创建人: 统一为导出操作人的信息，所属产品或关联产品统一为导出任务第一个产品的信息
- 数据文件包：同时将任务的数据文件、任务信息（task_info.yaml）与场景信息（playbook_info.yaml）打包为 tgz 数据文件包， 可用于「导入数据」或「大模型训练」、「数据升级」等
