#### 系统国际化（界面文案）：
- 界面文案、提示、报错等用户可见字符串，语言包存放在 `mgmt/i18n/i18n_system/{语种}.json`（如 `zh-CN.json`、`en-US.json`）
- key 采用按层级点号命名的扁平写法，如 `error.param_value_undefined`、`common.case_number`
- 翻译函数支持格式化占位符
- 切换语言后系统自动检测当前语言并重新加载对应语言包
- 新增文案：在 `zh-CN.json` 补中文 key、`en-US.json` 补对应英文 key

#### 菜单国际化：
- 菜单标题存于 `goadmin_menu` 表，译文维护在 `mgmt/i18n/i18n_menu/{语种}.yaml`（如 `en-US.yaml`）
- 文件为扁平「中文标题: 译文」映射，一行一项，例如 `用例管理: Case Mgmt`
- 中文标题即原文（恒等注册），英文从 `en-US.yaml` 读取译文，未命中回退中文原值
- 新增/修改菜单后，访问 `/admin/refresh-menu-i18n`（或重启应用）刷新菜单翻译注册，使新菜单生效

#### 数据语种切换：
- 在[环境-系统参数]页面点击「切换数据语种」按钮，可切换**测试用例、用例统计定义、定时任务、场景、数据**相关信息的显示语种（默认「跟随界面语言」）
- 支持语种：中文（zh-CN）、英文（en-US）等（由系统参数 supportLanguages 配置，值为 JSON 对象，示例：`{"zh-CN": "中文", "en-US": "English"}`）；未翻译的内容自动回退显示中文原文
- 切换语种前需先做「i18n同步」导出待翻译的中文骨架：
    - 用例统计定义列表：勾选统计定义 → 点击「i18n同步」→ 导出选中模块内用例原始数据（用例名称/类型/前置条件/测试范围/测试步骤/预期结果）及菜单、模块名到 `i18n/i18n_case/<模块>/zh-CN.yaml`、`i18n/i18n_caseCount/zh-CN.yaml`
    - 定时任务列表：勾选任务 → 点击「i18n同步」→ 导出任务名/描述及关联场景、关联数据的名称与描述到 `i18n/i18n_task/zh-CN.yaml`、`i18n/i18n_playbook/zh-CN.yaml`、`i18n/i18n_data/zh-CN.yaml`
- 同步后由翻译人员按骨架补充对应语种文件（如 `en-US.yaml`），补充完成后切换数据语种，已翻译的数据即显示对应语种

#### 同步知识库：
- 在[环境-系统参数]页面点击「同步知识库」按钮，将测试资产的原始数据导出为本地知识库文件，并上传到 AI RAG 知识库（如 Dify）
- 前置条件：
    - 系统参数 `aiRAGEngine` 需配置 RAG 连接信息，值为 JSON 对象（`baseUrl` / `apiKey` / `dataSetName` / `timeout`）
    - 仅 admin 用户具备同步权限
- 操作流程：点击「同步知识库」→ 弹出「同步类型」下拉框（场景/数据/任务/用例/接口/文档/全部）→ 选择类型确认后执行
- 各类型同步内容（先生成本地文件，再写入 RAG 数据集对应文档）：

| 类型 | 本地文件 | 数据来源 |
|------|---------|---------|
| 场景 | `playbook_info.yaml` | 历史执行通过（pass）的场景 |
| 数据 | `data_from_history.txt` | 历史执行通过（pass）的数据 |
| 任务 | `task_info.yaml` | 已结束（finished）的场景类任务 |
| 用例 | `testcase.txt` | 用例表全部用例 |
| 接口 | `<应用名>.txt` | env_config 中应用的 swagger 或本地接口 json |
| 文档 | 设计文档 | `mgmt/doc` 下的 ai/design/function/question 文档 |
| 全部 | 上述全部 | 上述全部 |

- 上传逻辑：读取 `aiRAGEngine` → 按 `dataSetName` 查找数据集（不存在则创建，默认名「Data4Test知识库」）→ 逐文件按文件名查找文档，已存在则更新、不存在则创建
- 同步结果：成功返回 `code 200`；失败（如无权限、连接信息缺失、类型未知）返回 `code 400` 并提示原因

#### 知识库数据包：
- 在[环境-系统参数]页面点击「知识库数据包」按钮，将知识库核心数据打包为 `.tgz` 压缩包供离线下载
- 前置条件：仅 admin 用户具备打包权限
- 打包内容（按时间戳生成 `knowledge_package_<yyyyMMddHHmmss>.tgz`，存放于下载目录）：

| 内容 | 文件 | 数据来源 |
|------|------|---------|
| 场景信息 | `playbook_info.yaml` | 历史执行通过（pass）的场景 |
| 任务信息 | `task_info.yaml` | 已结束（finished）的场景类任务 |
| 数据文件 | 各数据独立 `.yaml`（按数据文件名） | 历史执行通过（pass）的数据 |

- 操作结果：打包成功后返回下载链接，复制该链接在浏览器打开即可下载；失败则提示打包失败原因

#### 刷新报告：
- 「刷新报告」按当前最新执行数据重新计算统计指标，并将结果快照写入统计表；刷新为异步执行
- 三个页面的「刷新报告」入口：

| 页面 | 入口 | 生成报告类型 |
|------|------|--------|
| 环境-系统参数 | 「刷新报告」按钮 | 全局     |
| 产品配置 | 勾选产品后「刷新报告」 | 产品     |
| 应用配置 | 勾选应用后「刷新报告」 | 应用     |

#### 查看报告：
- 产品配置页：每行「查看报告」按钮 → 跳转产品报告页，读取该产品最新报告，若无则现场生成
- 应用配置页：每行「查看报告」按钮 → 跳转应用报告页，读取该应用最新报告，若无则现场生成
- 全局报告：由「统计报告」大盘页展示，读取最新的报告，若无则现场生成
- 结果报告管理：集中展示所有已生成报告，可查历史的报告
